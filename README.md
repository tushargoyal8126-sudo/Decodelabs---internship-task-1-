# DecodeLabs - Build the Future of the Web 🚀

A modern, responsive landing page for **DecodeLabs Full Stack Development Program**.  
This project focuses on clean UI design, responsive layouts, accessibility, and frontend fundamentals using pure HTML, CSS, and JavaScript.

## 🌐 Project Overview

DecodeLabs is a frontend-focused educational platform website designed to showcase:

- Full Stack Development training
- Learning modules
- Project-based learning approach
- Contact interaction
- Responsive user experience

The website follows a mobile-first approach with semantic HTML5 structure, modern CSS layouts, and Vanilla JavaScript interactions.
